# README media

- `hero.svg`: original vector artwork created for Prompt Studio, covered by the
  repository's MIT license. It illustrates the optimization loop, not measured results.
- `optimizer.png` and `minime.png`: unedited screenshots of this repository's real
  Django UI. Captured with a disposable local account/database, synthetic task
  text, and a localhost-only mock model catalog. The UI's endpoint badge reflects
  fixture configuration; no inference, learning, benchmark, or savings result
  is demonstrated by these screenshots.

To refresh screenshots, run the actual app against an isolated database, use
synthetic inputs, and capture the full page. Do not use customer runs, private
prompts, real credentials, or production data. Keep the images in this directory
so GitHub and source archives can render the README without external media hosts.
